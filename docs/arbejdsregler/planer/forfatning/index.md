# Forfatning

Planen bliver udførbar, når produktløfte og tekniske ændringer kan følges gennem samme konkrete forløb. [Visionen](vision.md) angiver hensigten, [scenarierne](scenarier.md) gør den efterprøvelig, og [implementeringsplanen](implementering.md) forbinder forløbene med kontrakter og kodeændringer. [Gennemgangen](gennemgang.md) læser dem samlet fra en udviklers perspektiv uden samtalehistorikken.

Området hører under [Planer](../index.md).
