# Validering

Validering guider næste udviklingsskridt gennem det faktisk kørende produkt. [Kriterierne](kriterier/index.md) afgør, hvornår hele capabilityen er færdig. [Metoderne](metoder/index.md) holder kontrollen let: smoke ved hver task og milepæl, let browserkontrol ved synlige ændringer og et helt scenarie med rettelsesrunder før en større feature erklæres færdig.

[Genbrugelige scenarier](scenarier/index.md) beskriver mål og observationer, ikke leveringsbevis. Ud over de tre niveauer vælges kun en kontrol ved en konkret risiko. Git er historikken, og koden er dokumentationen; der opbygges ingen suite, rutinemålinger eller bevisbogføring.
