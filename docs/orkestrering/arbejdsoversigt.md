# Aktuelle udviklingsleverancer

Arbejdet drives til færdigt og offentligt udgivet produkt efter [mandatet](mandat.md) og [udgivelsesvejen](../roadmap/chatgpt-app-mvp/implementering.md#aktivering-og-completion). Underagenter implementerer; `/root` ejer arkitekturreview, code review, slutbrugertest og deployment. Kun konkrete opgaver til Anders går i [indbakken](afklaringer/indbakke.md) og Gmail. Mærkerne følger [koordinationen](koordinering.md).

| Leverance og planlink | Igangsættelse og reference | Ejer, gren og arbejdsmappe | Mærke | Afhængighed og næste handling |
|---|---|---|---|---|
| [Autentificeret platformadgang](../roadmap/chatgpt-app-mvp/kontrakter/platform.md) | Igangsat; fuldførelsesmandat 24. oktober 2026 | `/root` | I gang | Native ejeradgang er genfundet gennem gentagne læse-/skrivekald; ingen aktivering kræves fra Anders. Kontrol af en anden rigtig konto og kontoisolation mangler fortsat; ejertesten er ikke samlet slutbrugeraccept |
| [Samlede brugerforløb](../roadmap/chatgpt-app-mvp/scenarier/index.md) | Igangsat; afhænger af autentificeret adgang | `/root` tester; underagenter retter på egne grene | I gang | 25 kildeposter er importeret og publiceret gennem native adminværktøjer. Søgning, relationer/træ og udløb på tværs af forælder/underemne virker live. Syntetisk foredrag er fundet, tilmeldt idempotent, genfundet og afmeldt; testforedraget er aflyst og aktive testtilmeldinger fjernet. Statistik er læst. Næste kontrol kræver normal ekstra konto til præferencesamtykke, roller/isolation og sletning samt faktisk MCP App-host. Ejerens personlige præferencer ændres ikke som test |
| [Faktiske events og varig drift](../roadmap/chatgpt-app-mvp/kontrakter/events.md) | Igangsat; afhænger af brugerforløb | `/root` ejer liveaktivering og scheduler-test; rettelser bestilles særskilt hos underagent | Afventer | Appens eventkilde og filterskema kan opdages i ChatGPT. Native admin-drain er kaldt med tom kø; den tidligere timebaserede opgave og event-genforsøg er nu standset efter Anders’ bestilling. Ingen faktisk callback/modtagelse er bevist. Opret et udtrykkeligt Work/Cloud-testabonnement i en kontekst, der tillader oprettelse; publicér match/ikke-match og afmeld. Bekræft callbackværter, faktisk senere retry og D1-bevaring/restore. Der oprettes ingen ekstra koordineringstimer |
| [Listing, sider og reviewmateriale](../roadmap/chatgpt-app-mvp/kontrakter/udgivelse.md) | Igangsat; uafhængig forberedelse fortsætter | `/root`; metadata og officielle ikoner er forberedt af underagenter | I gang | Bekræft udgiver via [HU-Q-20261024-01](afklaringer/indbakke.md); afklar derefter lande. De fire listing-URL'er kræver fortsat privat login, og politik/vilkår er udkast. PR #19 er udgivet privat som version 7: informations-GETs kræver ingen applikationsidentitet/database, mens MCP/health/skrivning er beskyttet; ubekræftet standardkontakt er fjernet. Officielle PNG-ikoner er forbundet og indeholdt i det eksisterende Sites-reviewudkast efter PR #18; ingen ekstra pluginpakke. Færdiggør offentlig adgang/indhold, optaget demo, fem positive/tre negative cases og normal revieweradgang. Færdig når materialet er sandt, tilgængeligt og cases kan gennemføres |
| [Offentlig review og installation](../roadmap/chatgpt-app-mvp/kontrakter/udgivelse.md) | Igangsat; afhænger af accepterede brugerforløb og reviewmateriale | `/root`; nødvendige identitets-/domænehandlinger til Anders via indbakke/Gmail | Afventer | Bevar kanonisk Sites-ejerskab; afklar understøttet indsendelsesvej, gennemfør verifikation/scans, indsend og løs fund. Færdig når godkendt release er publiceret, ny installation virker og faktisk katalogadresse aktiverer forsiden |

Planmodning og tekniske ejerafstemninger står på leverancen. Kun præcist afhængigt scope venter. En afsluttet række fjernes efter integration og completion; oversigten er ingen historisk log.
