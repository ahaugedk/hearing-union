# Levering

Afslutningen flytter gældende viden fra den midlertidige plan til dens varige hjem. [Fold ved completion](completion.md) forbinder denne overdragelse med registrering i den fælles udviklingsoversigt og oprydning i roadmap, arbejdsoversigt og aktive indgange. Den næste opgave får gældende principper og begrænsninger, mens afsluttede forbedringer kan læses samlet.

Området hører under [Planer](../index.md).
