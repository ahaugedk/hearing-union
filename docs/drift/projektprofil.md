# Projektets konkrete arbejdsgrundlag

Profilen er endnu ikke udfyldt. Erstat værdierne med faktiske forhold. Angiv ukendt, når noget endnu ikke er fastlagt, frem for at gøre et standardvalg til en beslutning. Produktvalg og procesmandat har hjem i [mandatet](../orkestrering/mandat.md) eller den relevante plan.

| Felt | Faktisk værdi |
|---|---|
| Projektnavn og produktejer | Ikke udfyldt |
| Produktfase | Før v1 eller efter første produktions-v1; endnu ikke fastlagt |
| Kildekode og integrationsgren | Ikke udfyldt |
| Orkestrator, arbejder- og reviewværktøjer | Ikke udfyldt |
| Arbejdsmapper, grenform og miljøejere | Ikke udfyldt |
| Adskilte porte, data og samtidige miljøer | Ikke udfyldt |
| Statisk kontrol eller build | Ikke udfyldt |
| Opstart med aktuel kode | Ikke udfyldt |
| Smoke-kommando mod kørende miljø | Ikke udfyldt |
| Mindste kerneforløb og normale indgange | Ikke udfyldt |
| Kerneflader og relevant mobilbredde | Ikke udfyldt; 390 px er et muligt udgangspunkt |
| Browser til visuel kontrol | Ikke udfyldt |
| Særskilt dev-reset og genopbygning | Ikke udfyldt |
| Diagnose og midlertidige artefakter | Ikke udfyldt; uden for versionerede docs |
| Forbrugspuljer og aflæsningsvej | Ikke udfyldt |
| Puljeprioritet, reserver og pausegrænser | Ikke udfyldt |
| Deployment og driftsansvar | Ikke udfyldt |

Kerneforløbet skal være lille og repræsentativt: faktisk login, central brugerhandling, gemt og genfundet resultat og eventuel agent- eller API-indgang, hvis den er central for produktet. Den ændrede feature afprøves særskilt uden at vokse ind i smoke. Profilen er ingen kørsel eller leveringsrapport.
