# Udvikling

Indsatsen vurderes efter den forbedring, den kan skabe for produktet. [Udviklingsøkonomien](oekonomi/index.md) forbinder billigt agentarbejde med kvalitet, læring og samlet omkostning; [arkitekturarbejdet](arkitektur/index.md) bruger samme vurdering, når et fund i én feature peger på en forbedring for hele produktet.

Området hører under [Arbejdsregler](../index.md).
