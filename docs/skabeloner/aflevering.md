# Kort aflevering

Brug højst ti linjer efter [completionreglen](../arbejdsregler/planer/levering/completion.md):

- Lavet: konkret adfærd og aftalt scope, der nu virker.
- Gren og commit: faktisk gren og commit for afleveringen.
- Smoke: bestået eller fejlet med første konkrete fejl; nævn kun kørt kontrol.
- Visuelt: relevant let kontrol eller scenariegennemgang og eventuelle åbne fund.
- Mangler: konkret uleveret scope, blokering eller intet, hvis det faktisk er dækkende.

Afleveringen går til review, ikke direkte til main. Den er ingen bevisrapport og indeholder ingen hashes over artefakter, måleregnskaber eller duplikeret udviklingshistorik. Orkestratoren ejer integration og samlet afslutning.
