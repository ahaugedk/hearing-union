# Arkitekturarbejde

En feature kan afsløre et problem, som flere dele af produktet betaler for. [Bred refaktorering](refaktorering.md) forbinder dette fund med en vurdering af fælles gevinst, ændrede garantier og relevante skaleringsrisici, før arkitekturen ændres.

Området hører under [Udvikling](../index.md).
