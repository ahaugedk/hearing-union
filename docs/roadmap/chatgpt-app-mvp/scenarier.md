# Målforløb for MVP-appens brugere

[Visionen](vision.md) ejer produktløfte og godkendelsesgrænse. De [konkrete brugerforløb](scenarier/index.md) følger forskellige aktører gennem normale ChatGPT-indgange og henviser til de relevante tekniske kontrakter. Brug hvert relevant forløb i den fase, hvor funktionen bygges; samlet gennemgang følger [implementeringen](implementering.md).

Scenarierne er forventninger, ikke udført validering. Brug reelle værktøjer, autentificering og persistens; fiktive personer og syntetiske arrangementer er indhold, ikke hardkodede svar eller særskilte produktveje. Et setupscript må etablere testindhold, men må ikke erstatte administratorens normale vedligeholdelsesfunktioner.

Ved gennemgang skal brugeren kunne forstå resultatet og næste handling, genfinde gemte oplysninger i en ny samtale og håndtere afslag, udløb eller ukendt udfald. UI gennemgås i ChatGPT på desktop og mobil, herunder tastatur, skærmlæserlabels og smal skærm; en lokal browserpreview beviser ikke hostintegrationen. Fund rettes og det berørte forløb gennemgås igen efter [projektets valideringsregel](../../arbejdsregler/levering/risikobaseret-validering.md).
