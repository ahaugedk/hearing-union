# Roadmap

[Høreforeningens ChatGPT-app – MVP](chatgpt-app-mvp/index.md) samler planen for kildebaseret viden, personlige præferencer, foredrag, proaktive MCP Events og administration gennem ChatGPT. Planen går fra afprøvning af Sites og login til fuld brugeroplevelse og offentlig indsendelse; den har fælles scope og separate roller for vision, scenarier og implementering.

Planen ejer produktvalg og godkendelsesgrundlag. [Arbejdsoversigten](../orkestrering/arbejdsoversigt.md) ejer klarhed, igangsættelse og trådansvar; placering i roadmappet autoriserer ingen implementering. Nye planer følger [de tre roller](../arbejdsregler/planer/struktur/tre-roller.md) og [planskabelonen](../skabeloner/plan/index.md).

Ved [completion](../arbejdsregler/planer/levering/completion.md) foldes varig viden, og en helt afsluttet plan samt dens links fjernes. [Parkeret materiale](../arbejdsregler/planer/afgraensning/parkerede-planer.md) indgår ikke i normalt arbejde.
