# Status for ændringen

Intet er leveret i denne skabelon. I den faktiske plan angives leveret arbejde med én linje pr. selvstændig leverance; link til varigt emne eller kode frem for leverings- og bevisafsnit.

Angiv uleveret scope og næste milepæl med link til [implementeringen](implementering.md). Uafklarede produktvalg linker til [beslutningshjemmet](beslutninger.md). [Arbejdsoversigten](../../orkestrering/arbejdsoversigt.md) ejer personer, tråde, readiness og igangsættelse; kopier ikke disse oplysninger hertil.

Delvis levering lukker ikke hele planen. Når hele scope er færdigt, fjernes planen efter completion i stedet for at blive et afsluttet planarkiv.
