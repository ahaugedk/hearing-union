# Drift

[Projektprofilen](projektprofil.md) ejer projektets konkrete produktfase, værktøjer, kommandoer og kapacitet. [Udviklingsmiljøet](udviklingsmiljoe.md) beskriver, hvordan den aktuelle kode startes, nulstilles og undersøges uden at blande miljøerne sammen.

Validering bruger det faktisk kørende miljø efter [metoderne](../validering/metoder/index.md). Føj kun yderligere driftsblade til, når et konkret emne har et selvstændigt læsebehov.
