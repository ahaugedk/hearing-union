# Udviklingsorkestrering

Én orkestrator i projektsamtalen fordeler implementering til underagenter efter [mandatet](mandat.md). Orkestratoren ejer selv arkitekturreview, code review, slutbrugertest og deployment. [Koordinationen](koordinering.md) forbinder bestilling og aflevering, og [reviewet](review.md) holder hele ændringen op mod regler og arkitektur før integration.

[Arbejdsoversigten](arbejdsoversigt.md) viser næste arbejde, ejer og igangsættelse. [Afklaringerne](afklaringer/index.md) samler kun produktspørgsmål klar til svar, mens uafhængigt arbejde fortsætter. [Kapacitet og kvoteværn](kvotevaern.md) og [planlagte kørsler](planlagte-koersler.md) gør ressourceforbrug, pause og genoptagelse eksplicitte. Opsætning er ikke aktivering.
