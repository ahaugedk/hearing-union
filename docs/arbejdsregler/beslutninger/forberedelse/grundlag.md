# Grundlag før anbefaling

Læs relevante beslutninger, planer og kode; henvis til kilder og skeln besluttet, implementeret og planlagt. Undersøg modstrid, ikke blot nyeste tekst.

Afklar problem/tekniske roller før teknologi. Genåbn valg med konkret grund; brug aktuelle primære kilder med pris, licens og integrationsansvar.

Afprøv afgørende usikkerhed med målrettet research/forsøg og sig kort, hvad der stadig er usikkert. Udforskning implementerer ikke stiltiende ikke-godkendte produktvalg; den underbygger [oplægget](oplaeg.md).

[Parkerede planer](../../planer/afgraensning/parkerede-planer.md) læses ikke uden bestilling, heller ikke via links.
