# Implementeringskontrakter

[Kontraktbladet](kontrakt.md) viser den nødvendige detalje for én ansvarlig del af leverancen. Opret flere blade efter problem og ejer, når de har selvstændigt læsebehov, og forklar deres sammenhæng her. [Implementeringen](../implementering.md) ejer den samlede rækkefølge og completion.
