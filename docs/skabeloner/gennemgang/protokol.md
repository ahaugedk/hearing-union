# Observationer under gennemgangen

Følg [scenariet](scenarie.md) gennem projektets [visuelle metode](../../validering/metoder/visuel-gennemgang.md). Erstat eksempelformen med konkrete checkpoints; gem ingen kørselsresultater i denne protokol.

| Checkpoint | Observer gennem produktet |
|---|---|
| Første indgang | Aktiv identitet, rolle og kontekst er forståelige |
| Central handling | Faktisk input giver det aftalte udfald og synlig næste handling |
| Adgangsgrænse | En anden relevant identitet får korrekt afslag uden indhold eller tællinger |
| Fejl eller ukendt udfald | Brugeren kan forstå status, og retry giver ingen blind gentagelse |
| Genfinding | Resultatet består og findes fra normal indgang efter genåbning |

Se checkpoints på desktop og relevant mobilbredde. Medtag tastatur, fokus, sprog, tomme tilstande og oplevet ventetid. En blokeret capability simuleres ikke. Produktagenters faktiske metode er åben; et script beviser ingen dømmekraft.

Noter samles midlertidigt under gennemløbet, rettes bagefter og slettes, når varige fund er foldet. Protokollen beskriver fremgangsmåden, ikke et leveringsbevis.
