# Økonomi

Billig udvikling ændrer, hvilke undersøgelser og ombygninger der kan betale sig. [Indsats og gevinst](indsats.md) vurderer arbejdet ud fra produktkvalitet, læring og samlet omkostning, så hverken vaner om forebyggelse eller byggetid alene bestemmer omfanget.

Området hører under [Udvikling](../index.md).
