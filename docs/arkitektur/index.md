# Arkitektur

[Principperne](principper.md) styrer, hvordan ansvar, konkrete kontrakter og kode hænger sammen. [Systemgrænserne](systemgraenser.md) er stedet for projektets egne komponenter, datakilder og adgangsbeslutninger. [Databevaring](bevaring.md) fastholder grænsen efter første produktionsversion.

Koden ejer felter, signaturer og algoritmer. Arkitekturen forklarer gældende ansvar, garantier og nødvendige begrundelser; forslag bliver i planen, og leveret adfærd beskrives først som leveret, når den er det.
