# Samarbejde

Produktejeren angiver retningen; agenterne omsætter den til et undersøgt, udførbart og leveret resultat. [Arbejdsdelingen](arbejdsdeling.md) holder de væsentlige produktvalg hos produktejeren og den løbende konkretisering hos agenterne. [Orkestreringen](../../orkestrering/index.md) fordeler arbejdet mellem selvstændige tråde og samler afklaringer, så udviklingen kan fortsætte mellem produktejerens besøg.

Området hører under [Arbejdsregler](../index.md).
