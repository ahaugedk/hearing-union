# Grænsen for væsentlige valg

Væsentlige valg ændrer produktløfte eller scope, centrale begreber, bruger- eller agentråderum, autoritet, adgang eller isolation, dataejerskab eller bevaring, udvidelses- eller leveringskontrakter, kompatibilitet eller central teknologi med betydning for muligheder, binding eller driftspris. Principvendinger er altid væsentlige, uanset kodemængde.

Agenten konkretiserer [grundlaget](../forberedelse/grundlag.md) og samler beslægtede valg i [oplæg](../forberedelse/oplaeg.md). Almindelige kodevalg træffes selv. Redaktion, der bevarer betydningen, kræver ingen ny produktbeslutning.

[Godkendelsen](../status-og-vendinger.md) dækker sit eksplicitte scope. Genforelæg kun ved væsentligt ændret valg eller bærende forudsætning.
