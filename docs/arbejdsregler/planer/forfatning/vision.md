# Forfatning af planvision

Beskriv konkret problem, berørt aktør, produktløfte, værdi og grænse med [visionens kompas](../../../produkt/retning/kompas.md).

Visionen ejer scope/status og linker scenarier, plan og gældende principper uden at kopiere trin/kontrakter. Selvstændige produktspørgsmål deles i blade; indgangen forbinder dem.

[Væsentlige valg](../../beslutninger/forberedelse/oplaeg.md) forelægges med tydelig status. Godkendt retning kan stadig have udkastleverancer; følg [gennemgangen](gennemgang.md). Reducér ikke v1 for at spare bygning.
