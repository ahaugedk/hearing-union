# Produktets vision

Projektets vision er endnu ikke udfyldt. Erstat denne tekst med det konkrete problem, hvem der oplever det, den ønskede forbedring og det samlede produktløfte. Navngiv også grænserne: hvad produktet ikke lover, og hvilke forudsætninger løftet bygger på.

[Kompasset](kompas.md) skal afspejle denne retning. Den enkelte ændrings scope og godkendelser bor i dens plan, ikke som udviklingshistorik her.
