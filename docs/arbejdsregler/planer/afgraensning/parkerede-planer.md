# Parkerede planer og genoptagelse

docs/roadmap/parkeret/ er hjem for parkerede idéer, ikke krav, kandidater, afhængigheder eller completion-kriterier. Opret kun grenen, når der er faktisk parkeret materiale.

Udelad fra søgning, kontekst, planlægning, implementering og dokumentkontrol; følg ikke links uden eksplicit bestilling om netop arbejdet.

Genoptagelse kræver ny konkret bestilling og afstemning med aktuelt produkt. Historisk godkendelse aktiverer intet; fokus er produktet og planerne i roadmappet.
