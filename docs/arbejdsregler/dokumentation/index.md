# Dokumentation

Viden får ét hjem efter [emneautoriteten](autoritet.md), så dokumenterne kan bruges uden kodekopier eller udviklingshistorik. [Forfatningen](forfatning.md) gør emner og sammenhænge læsbare, mens [OKF-formatet](okf.md) forbinder dem gennem metadata og links. [Vedligeholdelsen](vedligeholdelse.md) giver agenten ansvar for at opdage og rette uklare emnegrænser, navne og opdelinger ved opdateringer, så viden fortsat er let at finde.

Området hører under [Arbejdsregler](../index.md).
