# Arbejdsdeling mellem produktejeren og agenterne

Produktejeren sætter retning og godkender [væsentlige valg](../beslutninger/afklaring/vaesentlige-valg.md). Agenterne ejer research, konkretisering, teknisk korrekthed og fuldstændige planer og leverancer, også manglende kontrakter. Almindelige kodevalg afgøres selv.

Projektets stående procesmandat har hjem i [orkestreringsmandatet](../../orkestrering/mandat.md). Inden for det udfører agenterne selv research, forsøg, udviklingskontroller, afhængighedsinstallation, miljøopstart, udviklingsaktivering, særskilt valgt dev-reset, review og integration efter det tildelte ansvar. Allerede autoriserede proceshandlinger forelægges ikke igen. Et procesmandat godkender ingen nye produktvalg og giver ikke mere teknisk adgang end miljøet faktisk tillader.

Agenterne afstemmer konkret risiko, arbejdsgrundlag og ejerskab. De committer eget arbejde løbende på egne grene; Git er historikken. [Koordinationen](../../orkestrering/koordinering.md) fordeler review, fletning og push. Godkendt retning og igangsat implementering er forskellige oplysninger.

Væsentligt ændrede valg eller forudsætninger kræver revideret oplæg med konsekvens og begrundelse. Kun afhængigt arbejde venter; uafhængigt arbejde fortsætter. Et udtrykkeligt delegeret beslutningsmandat gælder inden for sit dokumenterede scope.

Modne produktspørgsmål går gennem [afklaringsarbejdsgangen](../../orkestrering/afklaringer/arbejdsgang.md). Teknisk modning, ejerafstemning og afhængigheder koordineres i [arbejdsoversigten](../../orkestrering/arbejdsoversigt.md). Udviklingsagenternes mandat er adskilt fra eventuelle agenters råderum inde i produktet.
