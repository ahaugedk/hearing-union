# Høreforeningens ChatGPT-app – MVP

[Visionen](vision.md) ejer det aftalte produktløfte og grænsen mellem planlægning, tekniske forslag og igangsættelse. [Scenarierne](scenarier.md) viser, hvordan brugere og administratorer skal kunne anvende og genfinde resultater gennem ChatGPT.

[Implementeringen](implementering.md) forbinder de forløb med faser og den resterende vej fra autentificeret accept til faktisk offentlig installation. Webdelen begrænses til installation og nødvendig reviewinformation i Høreforeningens identitet. De [tekniske kontrakter](kontrakter/index.md) fordeler detaljerne efter ansvar, mens [brugerforløbene](scenarier/index.md) kan læses enkeltvis ved den relevante fase.

Planen findes gennem [roadmappet](../index.md). Igangsættelse og leveranceejerskab hører i [arbejdsoversigten](../../orkestrering/arbejdsoversigt.md); dokumentplaceringen er ingen implementeringsbestilling.
