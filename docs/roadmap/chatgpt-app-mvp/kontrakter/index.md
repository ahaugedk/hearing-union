# Implementeringskontrakter

[Platformafprøvningen](platform.md) afklarer, hvad Sites og ChatGPT faktisk understøtter, før [fundamentet](fundament.md) fastlægger den fælles vej fra identitet og MCP-kald til database. Begge understøtter den samlede [implementeringsrækkefølge](../implementering.md).

[Viden](viden.md) ejer import, opslag og gyldighed. [Foredrag](foredrag.md) ejer arrangementer og tilmelding, mens [events](events.md) forbinder publicering med brugerens aktive abonnementer og varig levering. [Statistik](statistik.md) observerer brug uden at oprette personlige opslagshistorikker. [Udgivelse](udgivelse.md) forbinder funktionerne med datalivscyklus, drift og offentlig reviewadgang.

Kontrakterne er planforslag under [visionens scope og godkendelsesgrænse](../vision.md). De erstatter ikke gældende arkitektur eller dokumenterer færdig kode.
