# Bred refaktorering begrundes indefra og ud

Featurearbejde kan afsløre uforholdsmæssig pris, kompleksitet eller uensartethed. Undersøg bred ombygning frem for lapper; [billig agentudvikling](../oekonomi/indsats.md) gør den mulig.

Begrundelsen skal gavne produktet på tværs af features, ikke kun passe én bedre. Forelæg [væsentligt valg](../../beslutninger/afklaring/vaesentlige-valg.md) med navngiven gevinst/opgivne garantier og konkret begrundelse for gevinsten. Begrundes valget i performance, er grundlaget oplevet langsomhed eller et design, der [åbenlyst ikke skalerer](../../levering/skalering.md). Refaktorér bredt efter godkendelse.

Lap på hegn er signal om at ændre hegnet; det kræver konkretisering, ikke automatisk principgodkendelse.
