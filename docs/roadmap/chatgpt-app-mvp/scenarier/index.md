# Konkrete brugerforløb

[Vidensopslag](viden.md) følger kilden og dens senere gyldighed. [Foredrag](foredrag.md) følger en handling fra søgning til en tilmelding, der kan genfindes, mens [events](events.md) forbinder brugerens tilvalg med proaktiv besked og efterfølgende handling.

[Administration](administration.md) følger vedligehold og aggregeret indsigt. [Adgang](adgang.md) udfordrer konto- og rollegrænserne, og [kontosletning](konto.md) afslutter brugerens persistens og aktive leveringer. Forløbene konkretiserer [visionen](../vision.md) og bruges efter [scenariernes gennemgangsprincip](../scenarier.md).
