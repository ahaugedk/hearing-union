# Afklaring

Grænsen for agenternes selvstændige valg følger konsekvensen for produktet, ikke ændringens størrelse. [Væsentlige valg](vaesentlige-valg.md) identificerer de ændringer, der kræver produktejerens stillingtagen, mens almindelige kodevalg bliver hos agenterne.

Området hører under [Beslutninger](../index.md).
